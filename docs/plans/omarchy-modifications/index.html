Desktop changes

Grouped by purpose. Several areas share the same configuration or implementation.

Equal window tiling

A patched hy3 layout keeps sibling windows equally sized. It rebalances when windows open, close, move between workspaces, or when the active workspace changes.

A Hyprland version guard falls back to the stock layout if the plugin build does not match the running compositor.

Saved source: hy3.patch and dotfiles.lua

COSMIC-style directional movement

Super+Shift+arrows moves the focused window through tiling groups. Each press moves through one group relationship, with equal sizing afterward.

Super+arrows focuses windows. Super+T toggles floating and tiling. Super+L switches between hy3 and scrolling. The old Super+J arrangement shortcut is removed.

Local notes: ~/.config/hypr/equal-tiling-README.md

Keypad workspace shortcuts

Super+keypad switches workspaces. Add Shift to move the focused window and follow it. Add Shift and Alt to move it without following.

Keypad 1–9 selects workspaces 1–9; keypad 0 selects workspace 10. Both Num Lock states are supported.

Upstream: PR #11685

Right Alt push-to-talk dictation

Hold Right Alt to record with Voxtype, then release to transcribe. Uses the English base.en model, pauses media, and types the result with clipboard fallback.

Recordings can run for up to 120 seconds. Recording and transcription notifications are disabled.

Saved source: Voxtype configuration

Samsung ultrawide display setup

The Odyssey G95NC is configured for 7680×2160 at 240 Hz, with 1.2 desktop scaling and GDK_SCALE=1. It is matched by monitor description.

The portable restore makes this hardware configuration optional.

Saved source: monitors.lua

Custom display panel

Cloned the stock monitor widget as agentsmith1337.monitor, named “My Display.” Added a 1.2 scaling preset and wrapped scale buttons into rows of at most five.

The panel scrolls to keep the selected scale button visible during keyboard navigation.

Local source: ~/.config/omarchy/plugins/agentsmith1337.monitor/Panel.qml

Bar configuration

Added the third-party crmne.hyprmoncfg display configuration widget and the stock Tailscale widget. Replaced the stock monitor widget with “My Display.”

Local configuration: ~/.config/omarchy/shell.json

Penguin themes and wallpapers

Added cyberpunk-penguin-analytics-4k and cyberpunk-penguin-analytics-copper-4k. Both theme folders contain a palette and wallpaper.

Wallpaper copies are also available under Last Horizon. The two saved theme palettes currently match; the copper variant changes the artwork.

Local assets: ~/.config/omarchy/themes/ and ~/.config/omarchy/backgrounds/last-horizon/

Quant Alchemy Observatory screensaver

Built a native animated screensaver with the Quant Alchemy mark, copper rings, particles, a clock, and a synthetic chart. The renderer targets 30 frames per second.

Updated rendering to the display’s full 7680×2160 resolution. The artwork is stored locally and needs no network connection at runtime.

Local project: ~/Work/quantalchemy-screensaver/ · Visual reference

Password-protected screensaver integration

Added omarchy system lock --screensaver, personal lock and idle plugins, and launcher overrides. The animation runs inside the protected lock surface while the displays stay on.

A key reveals the password prompt without entering that wake key as a password character. After five seconds without input, the prompt returns to the animation. Normal locking retains its display blanking behavior.

The implementation supports optional QML artwork and a theme-background fallback, including video. The custom renderer unloads while the password prompt is visible.

Local project: ~/Work/omarchy-secure-screensaver/ · Implementation and test results

Portable Omarchy restore

Added python3 script/omarchy.py as a separate restore command. Preview is the default; --apply installs the saved overrides and --with-hardware includes monitor settings.

--build downloads a pinned hy3 source revision, verifies its checksum, applies the patch, and compiles against local Hyprland headers. Restore includes backups, rollback, and checks for later local edits.

Documentation: Personal Omarchy changes

What the restore covers

The dotfiles command restores a subset of this inventory.

Saved in the restore

  • Equal tiling and the hy3 source patch
  • Directional movement and keypad shortcuts
  • Right Alt binding and Voxtype configuration
  • Optional Samsung monitor settings

Separate local setup

  • Themes and wallpapers
  • Bar layout and display plugins
  • Observatory artwork and native renderer
  • Protected lock and idle plugins

Voxtype, its model, and its user service must already be installed and configured. The restore does not install packages or enable services. Personal shell plugins need upstream fixes and compatibility updates applied separately.

Sources & scope

This inventory was checked against GitHub contributions under ralphsmith80, the local Omarchy feature branches, the dotfiles history, and the current Hyprland and Omarchy configuration.

Terminal, tmux, and WirePlumber configuration were compared with installed defaults. They were not counted as personal modifications. Generic shell setup and unrelated application configuration are outside this inventory. Removed experiments without a surviving record may not appear here.

Local paths identify source files on the original workstation. GitHub links and the screensaver review page are usable from other devices. This page does not update automatically.
